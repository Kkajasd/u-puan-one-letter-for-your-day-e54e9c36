## The letter

**Z** — for "zero sleep".

## How it works

`main.ts` writes exactly one character, `Z`, to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Nothing else: no word, no gloss,
no punctuation. One byte, deterministic.
